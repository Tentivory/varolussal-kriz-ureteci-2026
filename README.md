# VAROLUŞSAL KRİZ ÜRETİCİ 2026

## Dünyanın En Ciddi, En Komik, En Gereksiz Programı

Bu repository, insanlığın yüz yıllardır peşinde koştuğu soruya cevap vermek için yaratıldı:

**"Hayatın anlamı nedir?"**

Cevap: Bu kodu çalıştırmak.

### Nasıl Çalışır?

```bash
python kriz_ureteci.py
```

Program şunları yapar:
- 1.5 saniye düşünür (düşünmeyi sever)
- 2 saniye daha düşünür (derin düşünür)
- Rastgele bir varoluşsal kriz üretir
- %10 ihtimalle gizli bir mesaj fışkırtır (gizli çünkü gizli)
- Sonunda ciddi bir damga vurur

### Özellikler

- Tamamen Türkçe
- Gerçekten çalışır
- Çay içerken daha iyi çalışır
- Sonsuz tekrar edilebilir (hayat gibi)
- Abartılı ciddiyet

### Neden Var?

Çünkü birileri "durduk yere aklın bir şeye takılsa bile repo aç" dedi.

### Uyarılar

- Bu program hayatınızı değiştirmez.
- Ama "vay be" dedirtir.
- GitHub Copilot bu kodu görse ağlardı. (Ağlamadı, denedik.)

### Katkı

Katkıda bulunmak istiyorsanız, lütfen kendi varoluşsal krizinizi issue olarak açın.
